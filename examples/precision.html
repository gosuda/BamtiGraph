What is being tested

Repeated renders of this implementation must agree. The 2× image must repeat each original pixel into a 2 × 2 block. These checks do not claim identity with a different rendering engine or an external screenshot.

ASCII pixel text is independent of installed font files. System text has closer classic typography and supports installed-language fonts, but its glyph pixels are host-dependent. Fixed input, options, library version and timezone data still matter.

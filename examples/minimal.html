Application code

const chart = BamtiGraph.traffic(timestamps, inbound, outbound, {
  title: 'Traffic - ether1',
  timeAxis: BamtiGraph.daily('Asia/Seoul'),
  yAxis: { minimum: 0, maximum: 240e6, majorStep: 50e6 },
  watermark: '' // Optional customer text in the right-hand vertical margin.
});
const result = chart.draw(document.querySelector('canvas'));
// On a user-initiated click:
result.download('traffic.png');

Timestamps are Unix epoch seconds, or Date objects. Values remain in the units you supply. This page builds its input arrays in minimal.js. The default watermark is empty; setting it adds only your own text.
